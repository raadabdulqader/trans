# نظام إدارة شركات النقل والنواقل البرية وربطها بالبوالص والصندوق

إضافة منظومة متكاملة لإدارة **شركات النقل المستقلة (النواقل)** وربطها بالبوالص الكمركية والصندوق المالي، بحيث يكون لكل شركة نقل حساب مستقل يوضح إجمالي مستحقاتها، الدفعات المسددة لها من الصندوق، والرصيد المتبقي بذمة المكتب، مع دعم إضافة أكثر من نقلة أو شاحنة بأسعار مختلفة داخل البوليصة الواحدة وأرشفة وصولات النقل.

---

## مراجعة المستخدم والقرارات المعتمدة

> [!IMPORTANT]
> تم بناء هذه الخطة بناءً على اختياراتك المؤكدة لضمان استقلالية حسابات شركات النقل ودقة الانعكاس المالي على البوالص والصندوق:

- **استقلالية شركات النقل وكشوفات الحساب:** شركات النقل هي جهات خارجية مستقلة عن شركتي التخليص (نقاء البصرة وصوت الجنوب)، ولكل شركة نقل ذمة مالية خاصة بها تفصل بين إجمالي أجور النقل المنفذة، المبالغ المسددة لها، والمتبقي بذمة المكتب بالدينار العراقي والدولار الأمريكي.
- **قسم متكامل لشركات النقل:** إضافة تبويب رئيسي مستقل في القائمة الجانبية باسم **شركات النقل (النواقل)** يتيح إضافة وتعديل شركات النقل، متابعة أرصدتها، استعراض وطباعة كشف حساب مفصل لكل شركة، وتسديد دفعات لها مباشرة من الصندوق.
- **تعدد النقلات والشاحنات داخل البوليصة:** إمكانية إرفاق نقلة واحدة أو عدة نقلات وشاحنات بأسعار وعملات مختلفة داخل نفس البوليصة، مع تسجيل: شركة النقل، وجهة النقل، عدد الشاحنات، اسم السائق، رقم الشاحنة/الهاتف، وأرشفة ورقة أو وصل استلام النقل مع المعاينة المباشرة.

---

## 1. النظرة العامة والمفهوم الأساسي

- **ماذا يقدم هذا التحديث:**
  1. **سجل شركات النقل المستقل:** إدارة بيانات شركات النقل البرية ومتابعة ذممها المالية (المستحق، المسدد، المتبقي) بمعزل عن حسابات الموظفين والمخلصين.
  2. **جدول النواقل داخل البوليصة:** قسم تفاعلي داخل نافذة إضافة/تعديل البوليصة يتيح تسجيل شاحنة أو أكثر بأسعار مختلفة، مع خيار تحديد ما إذا كانت أجرة النقل تُحمل على فاتورة الزبون أو تُقيد كذمة نقل مباشرة لشركة النقل.
  3. **سندات صرف تسديد النواقل:** تسديد أجور شركات النقل (كلياً أو على شكل دفعات) من الصندوق مع انعكاس فوري في خزينة الشركة وكشف حساب الناقل، ودعم الإلغاء الدفتري المحاسبي (VOID).
  4. **تقارير النقل والذمم:** إدراج كشوفات حساب شركات النقل وتفاصيل أجور النقل ضمن التقارير المالية الشاملة.
- **المستفيدون:** محاسبو المكتب، مسؤولو متابعة الشحنات والترانزيت، والإدارة المالية.
- **القيمة المضافة:** ضبط ديون شركات النقل ومنع تداخلها مع سلف المخلصين أو مصاريف المكتب اليومية، مع توثيق كامل لحركة كل شاحنة وسائق ووصل استلام.

## 2. تجربة المستخدم والتصميم البصري

### تدفقات الاستخدام الرئيسية
1. **إدارة شركات النقل (تبويب شركات النقل):**
   - يعرض شريط مؤشرات مالية أعلى الصفحة (إجمالي مستحقات شركات النقل، إجمالي المسدد من الصندوق، إجمالي المتبقي بذمة المكتب بالدينار والدولار).
   - جدول وبطاقات شركات النقل مع أزرار سريعة لكل شركة: **تسديد دفعة لشركة النقل**، **كشف حساب تفصيلي وطباعة**، **تعديل البيانات**.
2. **إضافة نقلات متعددة داخل البوليصة:**
   - داخل نافذة البوليصة، يوجد قسم **نقل البضائع والنواقل البرية**.
   - يمكن للمستخدم الضغط على **إضافة نقلة / شاحنة** لإدراج سطر نقلة جديد يتضمن:
     - اختيار شركة النقل (مع إمكانية إضافة شركة نقل سريعة).
     - وجهة النقل (مثلاً: أم قصر ← بغداد / البصرة / أربيل).
     - عدد الشاحنات، اسم السائق، ورقم السيارة / الهاتف.
     - عملة النقل (دينار أو دولار)، مبلغ أجرة شركة النقل، والمبلغ المحمل على الزبون (إن وجد).
     - زر **أرشفة وصل النقل** لرفع صورة أو ملف PDF لوصل استلام السائق ومعاينته فوراً.
3. **تسديد دفعات شركات النقل من الصندوق:**
   - نافذة تسديد من عمودين تتيح اختيار شركة النقل والبوليصة المرتبطة (أو تسديد دفعة عامة على الحساب)، تحديد العملة والمبلغ وسعر الصرف، وعمولة التحويل (على الشركة أو على شركة النقل)، مع زر **حفظ وطباعة سند الصرف**.

### الهوية البصرية والتنسيق
- **السمة اللونية:** الالتزام بالسمة الداكنة الاحترافية للنظام (`#0F172A` للخلفيات الأساسية، `#020617` للحقول والأسطح الداخلية) مع تمييز قسم النواقل باللون البرتقالي/الكهرماني والتركواز لسهولة التفرقة البصرية عن البوالص الكمركية.
- **الخطوط والأرقام الجدولية:** استخدام الأرقام أحادية المسافة (`font-mono tabular-nums`) لكافة المبالغ المالية، أرقام الشاحنات، والتواريخ لضمان المحاذاة العمودية الدقيقة في الجداول والكشوفات.
- **تخطيط النوافذ:** تصميم نوافذ إضافة شركة النقل، تسديد دفعة الناقل، وكشف حساب شركة النقل بنظام **العمودين (2-Column Layout)** لضمان ظهور كافة التفاصيل والأزرار دون اقتصاص.

## 3. القرارات المحاسبية والهندسية

- **القرار 1: فصل ذمة شركة النقل عن سلف المخلصين**
  - *النهج المختار:* إنشاء كيان محاسبي مستقل لشركات النقل (`TransportCompany`) وحركات نقل البوليصة (`BillTransportTrip`) وسندات تسديد النواقل.
  - *السبب:* شركات النقل جهات خارجية مستقلة تتعامل بنظام الحساب الجاري والدفعات الآجلة، ولا يصح خلطها مع سلف المخلصين الكمركيين.
- **القرار 2: دعم تعدد النقلات وأرشفة وصل النقل لكل نقلة/بوليصة**
  - *النهج المختار:* تخزين قائمة نقلات (`transportTrips`) داخل البوليصة بحيث يمكن للبوليصة الواحدة أن تحتوي على نقلة واحدة أو عدة شاحنات بأسعار ووجهات مختلفة، مع مرفق أرشيف خاص بوصل النقل.
  - *السبب:* البوليصة التي تضم عدة حاويات قد تُنقل عبر أكثر من شاحنة أو إلى وجهات مختلفة وبأسعار متباينة.
- **القرار 3: تطبيق قاعدة الإلغاء الدفتري (VOID) على دفعات شركات النقل**
  - *النهج المختار:* أي دفعة مسددة لشركة نقل من الصندوق لا تُحذف فيزيائياً، بل تُلغى دفترياً مع ذكر السبب وإرجاع المبلغ فوراً إلى رصيد الصندوق وإعادة الذمة لحساب شركة النقل.
  - *السبب:* الامتثال الكامل للقواعد المحاسبية الصارمة للنظام وحماية تسلسل سندات الصندوق.

## 4. البنية التقنية وهيكلة البيانات

### مخطط تدفق البيانات والمكونات

```
┌────────────────────────────────────────────────────────────────────────────┐
│                        قاعدة البيانات المحلية (Storage)                     │
│  • سجل شركات النقل (TransportCompany)                                      │
│  • جدول النقلات داخل البوليصة (BillTransportTrip[])                         │
│  • سندات تسديد النواقل وحركات الصندوق (TreasuryTransaction / Receipt)      │
└───────────────────┬────────────────────────────────────┬───────────────────┘
                    │                                    │
                    ▼                                    ▼
┌───────────────────────────────────────┐  ┌─────────────────────────────────┐
│     نافذة البوليصة (Transaction)      │  │   تبويب شركات النقل (النواقل)   │
│  • تفعيل نقل البضائع للبوليصة         │  │  • بطاقات وجدول شركات النقل     │
│  • إضافة أكثر من نقلة/شاحنة بسعر مختلف│  │  • إجمالي النقلات / المسدد /    │
│  • عدد الشاحنات + الوجهة + السائق     │  │    المتبقي لكل شركة نقل         │
│  • رقم السيارة + أرشفة وصل النقل      │  │  • كشف حساب شركة نقل + طباعة    │
└───────────────────┬───────────────────┘  └─────────────────┬───────────────┘
                    │                                        │
                    └───────────────────┬────────────────────┘
                                        ▼
┌────────────────────────────────────────────────────────────────────────────┐
│                     الصندوق والتقارير المالية الشاملة                      │
│  • نافذة تسديد دفعة لشركة النقل (من عمودين + دعم العمولة وسعر الصرف)        │
│  • انعكاس فوري في رصيد الصندوق (مع دعم الإلغاء الدفتري VOID)                │
│  • تقرير أرباح ومصاريف البوالص + تقرير كشف حساب وذمم شركات النقل            │
└────────────────────────────────────────────────────────────────────────────┘
```

### نموذج البيانات وحالات التفاعل
1. **بيانات شركة النقل (`TransportCompany`):**
   - المعرف، اسم شركة النقل، اسم المسؤول، رقم الهاتف، العنوان، الملاحظات، وتاريخ الإنشاء.
2. **بيانات النقلة داخل البوليصة (`BillTransportTrip`):**
   - المعرف، معرف شركة النقل واسمها، وجهة النقل (`destination`)، عدد الشاحنات (`truckCount`)، اسم السائق (`driverName`)، رقم الشاحنة/السيارة (`truckPlateNo`)، هاتف السائق، عملة النقلة (`IQD` / `USD`)، كلفة شركة النقل (`carrierCost`)، أجرة النقل على الزبون (`customerCharge`)، هل تضاف أجرة النقل على فاتورة الزبون (`addToCustomerBill`)، ومرفق وصل استلام النقل (`transportDocument`).
3. **حساب الذمم والتسديدات (`CarrierFinancialSummary`):**
   - دالة محاسبية تحسب لكل شركة نقل: مجموع `carrierCost` من كافة البوالص الفعالة (غير الملغاة)، مجموع الدفعات المسددة لها من الصندوق (غير الملغاة دفترياً)، والرصيد المتبقي بذمة المكتب لكل عملة.
